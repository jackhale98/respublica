# Errata

Suspected errors in imported texts are recorded here, not fixed in place. A
human checks each one against a page image of an authoritative printing. If
it is confirmed, the importer applies the correction (with a comment pointing
to the entry) and the entry records the outcome. Refs are never renumbered.

Each entry gives the ref, the suspected problem, where it is in the raw
source, and its status.
